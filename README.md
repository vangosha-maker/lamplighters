# Фонарщики

Пошаговая тактика-головоломка в браузере. У фонарщиков нет оружия: мороков нужно двигать ветром, крюком и зеркалом так, чтобы они били друг друга, тонули в каналах и промахивались мимо фонарей.

- **Ночной дозор** — кампания из пяти ночей со случайными картами.
- **Этюды** — 12 задач в один ход, каждая проверена перебором.

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не нужны; шрифты подгружаются с Google Fonts.

## Управление

Мышь или касание. Клавиши: `1`–`3` выбрать фонарщика, `Z` отмена, `R` сброс хода, `Пробел` закончить ход.
